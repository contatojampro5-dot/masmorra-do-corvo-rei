# Efeitos sonoros do jogo
Os 18 efeitos foram sintetizados em código para o Masmorra do Corvo Rei (Apolo / Olimpo).
Não usam gravações nem amostras de terceiros. Pertencem ao projeto.
Para gerar de novo: `python3 tools/sfx/sfx.py saida/` (precisa de Python 3, numpy, ffmpeg e `tools/musica/celta.py` ao lado).
